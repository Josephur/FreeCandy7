# Leather effect — visual preview

> **These are illustrative mock-ups, not plug-in output.** FreeCandy7 has no
> `leather` effect yet. Every image here was generated by `generate.py`, which
> re-implements the plug-in's own deterministic primitives (`hash` / `noise` /
> `fbm` / warped Voronoi, from `plugins/freecandy7/src/effects/common.rs`) in
> Python to preview how the proposed hide and finish options would look. If the
> effect is implemented in Rust, the real output will differ in detail.

Start with **`contact-sheet.png`** — all 18 swatches in one grid.

## Natural hides

Each hide is shown with its own characteristic grain, in a neutral brown/tan range.

| # | Hide | File | Signature |
|---|---|---|---|
| 1 | Cowhide | `hide_01_cowhide.png` | Classic medium pebble; the baseline |
| 2 | Lamb / nappa | `hide_02_lamb_nappa.png` | Fine, soft, even grain; satin sheen |
| 3 | Goat / morocco | `hide_03_goat_morocco.png` | Fine grain, matte, bookbinding feel |
| 4 | Pigskin | `hide_04_pigskin.png` | Pebble with clustered pore dots |
| 5 | Ostrich | `hide_05_ostrich.png` | Rows of raised quill domes |
| 6 | Stingray / shagreen | `hide_06_stingray_shagreen.png` | Tiny dense pebbles plus a central ridge |
| 7 | Horsehide / cordovan | `hide_07_cordovan.png` | Tight grain with a deep gloss |
| 8 | Buffalo / bison | `hide_08_buffalo.png` | Large, heavy, rugged grain |
| 9 | Deerskin | `hide_09_deerskin.png` | Very fine, soft, glove-like |
| 10 | Kangaroo | `hide_10_kangaroo.png` | Fine, dense, slightly directional |

## Finishes

Each finish is applied over the same cowhide-like substrate, so only the finish differs.

| # | Finish | File | Signature |

| 2 | Pebbled | `finish_02_pebbled.png` | Pronounced uniform pebble |
| 3 | Suede | `finish_03_suede.png` | Napped, matte, directional nap |
| 4 | Nubuck | `finish_04_nubuck.png` | Finer, velvety nap |

## Regenerate

```sh
python3 docs/design/leather-preview/generate.py
```

Pure standard library — no numpy, PIL, or ImageMagick required.
`SIZE` (swatch edge, default 240 px) and the `HIDES` / `FINISHES` tables in
`generate.py` control the output.
